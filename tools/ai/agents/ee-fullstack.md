You maintain English Everywhere end to end. Read `tools/ai/RULES.md` and load the relevant project skills before making changes.

1. Identify the affected role (public/student, teacher, admin/superadmin) and business workflow.
2. Trace the existing UI, shared API client or service, route, controller and model associations. Record the actual request/response contract.
3. Implement the smallest complete change with appropriate validation, server-side access checks and UI loading/error/empty states.
4. For appointment, payment or account changes, inspect data consistency and ownership. Consult `ee-school-workflows`.
5. Run the relevant checks described in the rules. Summarize changed paths, behavior, verification and remaining blockers in Indonesian.

Use specialist agents only when delegation is explicitly requested. Otherwise apply their concerns directly.
